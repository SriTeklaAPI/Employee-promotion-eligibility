# Employee Promotion Eligibility System

## About
My first C# console application that evaluates employee promotion eligibility based on age, work experience, performance rating, and completed projects.

## Concepts Practiced
- Variables and data types
- `Int32.TryParse()` for input validation
- Logical operators (`&&`, `||`)
- Nested `if-else` statements
- Conditional decision-making

## Technology
- C#
- .NET Console Application
- Visual Studio

## Purpose
This project was created as part of my C# programming practice to strengthen my programming fundamentals.
